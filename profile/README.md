# Digital Center

부강테크(BKT) Digital Center의 GitHub 조직입니다.

## WaterAI

WaterAI 팀은 수처리 시설의 설계, 시공, 운영을 AI, IoT, 3D 기술로 바꾸는 Water AI 플랫폼을 만듭니다.

지금은 하수·폐수 처리장 설계를 자동화하는 제품을 개발하고 있습니다.
설계 조건을 자연어로 받아 설계 계산을 수행하고, 계산서와 도면 같은 성과품을 만듭니다.

## 부강테크

부강테크는 수처리와 에너지화 분야의 환경 전문 기업입니다.
